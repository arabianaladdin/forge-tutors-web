# Forge Tutors

Client-facing website for Forge Tutors — 1-to-1 GCSE Maths tutoring, grades 7-9.

## Stack

- Single-page site (`index.html`), styled with Tailwind CSS (CDN)
- Fraunces + Manrope typography
- Calendly embed for live booking/scheduling
- Deployed on Netlify

## Local development

Open `index.html` directly, or serve it locally:

```bash
npx serve .
```

## Deployment

Deployed via Netlify, connected to this repository's `main` branch.
